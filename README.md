# Terraform for Genesys Cloud

A community-driven repository containing practical Terraform examples, documentation, and reference material for managing Genesys Cloud using the official Genesys Cloud Terraform Provider.

## Purpose

The official Genesys Cloud Terraform Provider repository contains provider source code, development tooling, tests, and documentation. While that repository is the authoritative source, it can be overwhelming for administrators, consultants, architects, and developers who simply want working Terraform examples.

This repository focuses on:

- Practical implementation examples
- Terraform resource samples
- Data source examples
- Provider configuration examples
- Common Terraform patterns for Genesys Cloud
- Documentation extracted from the official provider repository
